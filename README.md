# 0x3mr.github.io

my personal site. built with SvelteKit.

## dev

```bash
npm install
npm run dev
```

## structure

- `src/routes` — pages
- `src/lib/components` — sections (hero, experience, projects, work, likes/dislikes)
- `src/lib/work` — media for the previous work gallery
- `src/lib/posts` — blog posts
- `src/lib/imgs` — misc images (project covers, etc.)

that's it.
